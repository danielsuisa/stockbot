# Sector rotation turnover — 2007 through September 2026

## Queue preface

This count was not re-run. The turnover gate below stays **NO-GO** at 9.82 single-fund replacements a year. There is no per-trade return list, so required n is not computed and the sample-size gate is not applied. A future fill would use IBKR Pro Fixed, from each order's shares and price. This file has no realized gains, so the after-tax line is not computed. The earlier sector return report is a prior trial under the old commission and was not re-priced.

Holdings only. No return is computed. The book is the preregistered sector rule: at each completed month-end, rank the nine original SPDR sectors by the adjusted close at t−1 divided by the adjusted close at t−6, minus one, and hold the top two. If SPY's month-end adjusted close is strictly below its 200-day average, the held set is empty (cash). XLRE and XLC are not in the universe. Prices are Yahoo Finance adjusted closes from 2005-01-03 through 2026-10-15, so the 2007 signals have their lookback. This count does not place or transmit an order.

A single-fund replacement counts each name that changed hands. Cash is the empty set. A one-for-one swap is one replacement. Leaving two funds for cash counts as two, and leaving cash for two funds counts as two. A name that stays counts as zero. Staying in cash counts as zero.

The changes counted are those whose new month-end falls on 2007-01-31 through 2026-09-30. The month that contains the run date, October 2026, is not a month-end. December 2006 is the baseline for January 2007 and is not itself a step. The average is the total replacements divided by the span from the first step to the last, in years of 365.25 days.

**9.82 single-fund replacements per year.** 193 replacements across 237 month-ends, from 2007-01-31 to 2026-09-30 (19.663 years).

The pre-registered gate is 2 per year. 9.82 is above 2. **T5 is closed NO-GO.** The return test is not run.

Of the 237 steps, 93 replaced nothing, 95 replaced one fund, and 49 replaced two. Fifty of the destination months are cash. The same count with the cash filter ignored, always holding the top two, is 179 replacements, 9.10 per year. That reading is also above 2.
